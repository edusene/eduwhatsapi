Visão geral

A API do {{ app_name }} é uma camada REST sobre a WhatsApp Cloud API oficial da Meta. Você chama a nossa API com uma chave interna; nós chamamos a Meta com o token do número conectado — que nunca é exposto.

URL base
{{ base }}
Formato
JSON (UTF-8). Datas em ISO 8601 (UTC).
Especificação
OpenAPI 3 (YAML)
O formato dos objetos de mensagem segue a documentação oficial da Cloud API. Recursos que dependem de aprovação da Meta (modelos, limites de envio, verificação do negócio) continuam sujeitos às regras dela.

Autenticação

Crie uma chave em Painel → Chaves de API e envie-a no cabeçalho Authorization. A chave completa aparece uma única vez; guardamos apenas um hash.

Authorization: Bearer sk_live_SUA_CHAVE

Cada chave tem escopos. Uma chamada sem o escopo necessário retorna 403 insufficient_scope.

Modo de teste

Chaves sk_test_ passam por toda a validação, mas não chamam a Meta: a resposta traz "test_mode": true e um id wamid.TEST…. Use-as para montar fluxos sem gastar mensagens. Para enviar de verdade, use uma chave sk_live_.

Erros e limites

Todo erro segue o mesmo envelope. Informe o request_id ao suporte.

    "meta_error": { "code": 131047, "message": "Re-engagement message", "fbtrace_id": "A…" }

Limite padrão: 120 requisições por minuto por chave (configurável pelo operador da plataforma). Os limites de mensagens da Meta (por número e por qualidade) se aplicam à parte.

Idempotência

Envie Idempotency-Key (8–128 caracteres, único por mensagem) para repetir com segurança após um erro de rede ou timeout. Se a mesma chave chegar de novo, devolvemos a resposta original com Idempotent-Replayed: true — a mensagem não é reenviada.

Enviar mensagem

POST/whatsapp/{phone_number_id}/messages

Escopo messages:send. Responde 201 quando a Meta aceita a mensagem; o status final (entregue, lida, falhou) chega por webhook.

curl -X POST {{ base }}/whatsapp/PHONE_NUMBER_ID/messages \
  -H "Authorization: Bearer sk_test_SUBSTITUA_PELA_SUA_CHAVE" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: pedido-1234-aviso" \
  -d '{"to": "5511999998888", "type": "text", "text": {"body": "Mensagem de teste"}}'

Modelos

GET/whatsapp/{phone_number_id}/templates?status=APPROVED

Lista os modelos da conta do WhatsApp (WABA) diretamente na Meta. Modelos são criados no painel (página do número) ou no WhatsApp Manager e passam por análise da Meta.

Mídia

POST/whatsapp/{phone_number_id}/media

Upload multipart/form-data com o arquivo no campo file. Retorna {"data": {"id": "…"}} para usar em image.id, document.id etc.

curl -X POST {{ base }}/whatsapp/PHONE_NUMBER_ID/media \
  -H "Authorization: Bearer sk_live_SUA_CHAVE" -F "file=@foto.jpg;type=image/jpeg"
GET/whatsapp/{phone_number_id}/media/{media_id}

Baixa (stream) uma mídia recebida — o media_id chega no webhook message.received. A Meta mantém mídias recebidas por tempo limitado; baixe e guarde no seu sistema se precisar.

Conversas (plano API + Chat)

Uso

GET/usage?days=30

Validar a assinatura

Calcule HMAC-SHA256(segredo, timestamp + "." + corpo_bruto) e compare com o cabeçalho em tempo constante. Rejeite timestamps com mais de 5 minutos para evitar replay. O segredo whsec_… aparece uma vez ao criar o webhook.

# Python (Flask)
import hashlib, hmac, time
from flask import request, abort

SECRET = "whsec_SEU_SEGREDO"

def verificar():
    ts = request.headers.get("X-Webhook-Timestamp", "")
    assinatura = request.headers.get("X-Webhook-Signature", "")
    if not ts.isdigit() or abs(time.time() - int(ts)) > 300:
        abort(400)
    esperado = "sha256=" + hmac.new(SECRET.encode(), ts.encode() + b"." + request.get_data(),
                                    hashlib.sha256).hexdigest()
    if not hmac.compare_digest(esperado, assinatura):
        abort(401)
// Node.js (Express com express.raw({ type: "application/json" }))
const crypto = require("crypto");
function verificar(req) {
  const ts = req.get("X-Webhook-Timestamp");
  const esperado = "sha256=" + crypto.createHmac("sha256", process.env.WEBHOOK_SECRET)
    .update(ts + "." + req.body).digest("hex");
  const recebido = req.get("X-Webhook-Signature") || "";
  return Math.abs(Date.now() / 1000 - Number(ts)) < 300 &&
    recebido.length === esperado.length &&
    crypto.timingSafeEqual(Buffer.from(esperado), Buffer.from(recebido));
}

Exemplo com n8n

  1. Crie um nó Webhook (método POST) e copie a URL de produção.
  2. No painel, cadastre essa URL em Webhooks com o evento message.received.
  3. Processe {{ '{{' }} $json.body.data.message.text.body {{ '}}' }} (texto recebido) e o remetente em data.contact.wa_id.
  4. Para responder, use um nó HTTP Request: POST para {{ base }}/whatsapp/PHONE_NUMBER_ID/messages, cabeçalho Authorization: Bearer sk_live_… e corpo JSON como nos exemplos acima.
